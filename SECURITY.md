# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| 2.x     | :x: (update to 3.x) |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly via email:

**matt.a.denney@gmail.com**

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You should receive a response within 7 days. Please do not open a public GitHub issue for security vulnerabilities.
