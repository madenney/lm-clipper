## Lunar Clipper 3.0.1

Video Tools, your own overlay font and size, and recording fixes.

### What's new

- **Video Tools:** Stitch is now a film button that is always in the top bar. Combine clips into one video, compress it to a smaller size for uploading, or compress one video by itself. Each quality shows the size it will make, a combine can be cancelled, and your last quality is remembered.
- **Your own overlay font:** Settings > Overlay > Font > Import font (.ttf, .otf, .ttc, .woff, .woff2).
- **Overlay text size**, with a preview drawn exactly as the video will show it.
- The overlay text sits in the middle of its box, and the box runs right to the edge of the video.

### Fixed

- Recording at 2.5x or 4x widescreen, or at 2x with widescreen off, made no video on Linux.
- Opening an edgeguard (or any clip that is not a combo) now plays that clip in the replay player instead of showing the whole game.

### Install

| System | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | `Lunar-Clipper-Setup-3.0.1.exe` |
| Ubuntu / Debian | `Lunar-Clipper-3.0.1.deb` (recommended) |
| Other Linux | `Lunar-Clipper-3.0.1.AppImage` (needs `libfuse2`; see the README) |

Compare a download with `SHA256SUMS.txt` (`sha256sum` on Linux, `Get-FileHash` in Windows PowerShell).

**Already on 3.0.0?** Clipper offers the update itself at startup (or use **Help > Check for Updates**). Your projects and settings are kept.

**Windows will warn you the first time.** This installer is not code-signed yet. SmartScreen shows "Windows protected your PC": click **More info, then Run anyway**. On Windows 11 with **Smart App Control** on, Windows may block it with no "Run anyway": check the SHA-256, then either turn Smart App Control off for the install or wait for the signed build.

**Requirements:** Windows 10 or 11 (64-bit; only Windows 11 with an NVIDIA GPU has been tested), a Slippi Dolphin install and a Melee NTSC 1.02 ISO (Lunar does not provide one). Linux is experimental. There is no Mac version.

### Known issues

- Windows 10, AMD and Intel graphics, and Linux are not tested yet and may not work.
