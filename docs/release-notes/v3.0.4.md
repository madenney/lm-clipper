## Lunar Clipper 3.0.4

A safety update. Please install it.

### Safety

- **Clipper now needs Slippi Playback Dolphin 3.5.2 or newer.** Older Playback Dolphins could run harmful code hidden in a replay file on the computer that plays it (fixed by Slippi in 3.5.2, January 2026). Clipper no longer plays or records with an older one. If yours is older, open the Slippi Launcher: it updates Dolphin by itself. Then try again.
- Invisible and right-to-left characters in player names are left out of video file names, so a name cannot disguise a file.

### Changes

- The usage-stats notice has a clear OK button.

### Install

| System | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | `Lunar-Clipper-Setup-3.0.4.exe` |
| Ubuntu / Debian | `Lunar-Clipper-3.0.4.deb` (recommended) |
| Other Linux | `Lunar-Clipper-3.0.4.AppImage` (needs `libfuse2`; see the README) |

Compare a download with `SHA256SUMS.txt` (`sha256sum` on Linux, `Get-FileHash` in Windows PowerShell).

**Already on 3.0.x?** Clipper offers the update itself at startup (or use **Help > Check for Updates**). Your projects and settings are kept.

**Windows will warn you the first time.** This installer is not code-signed yet. SmartScreen shows "Windows protected your PC": click **More info, then Run anyway**. On Windows 11 with **Smart App Control** on, Windows may block it with no "Run anyway": check the SHA-256, then either turn Smart App Control off for the install or wait for the signed build.

**Requirements:** Windows 10 or 11 (64-bit; only Windows 11 with an NVIDIA GPU has been tested), Slippi Playback Dolphin 3.5.2 or newer and a Melee NTSC 1.02 ISO (Lunar does not provide one). Linux is experimental. There is no Mac version.

### Known issues

- Windows 10, AMD and Intel graphics, and Linux are not tested yet and may not work.
