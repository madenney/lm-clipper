## Lunar Clipper 3.0.0

The Lunar Database is built in: find any combo or game and clip it without leaving Clipper.

### What's new

- **Download games:** search the whole Lunar Database by player, character, stage or tournament and download the games straight into your library.
- **Pre-parsed moments:** search combos and edgeguards across every game in the database, then download only the games you need.
- **Fast, resumable downloads** that come straight from storage. Downloaded games are kept compressed, so they take about 9 times less disk space. A Downloads panel shows what is coming.
- **Hidden recording** by default, so you can keep using your computer while clips record, and a fast recording quality that is high quality in a fraction of the time.
- **AI Filter step:** describe what you want, paste your own AI assistant's answer, and Clipper runs it. Clipper never calls an AI itself.
- A new first screen and Welcome guide, Play / Record / Stitch at the top left with every recording option in one Options menu, keyboard-friendly dialogs and clip grid, and clearer messages when an import or opening a project does not work.
- Games with a computer player are left out by default, with an option to include them. A game that cannot be read is skipped and counted instead of stopping a whole run.

### Install

| System | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | `Lunar-Clipper-Setup-3.0.0.exe` |
| Ubuntu / Debian | `Lunar-Clipper-3.0.0.deb` (recommended) |
| Other Linux | `Lunar-Clipper-3.0.0.AppImage` (needs `libfuse2`; see the README) |

Compare a download with `SHA256SUMS.txt` (`sha256sum` on Linux, `Get-FileHash` in Windows PowerShell).

**Windows will warn you the first time.** This installer is not code-signed yet. SmartScreen shows "Windows protected your PC": click **More info, then Run anyway**. On Windows 11 with **Smart App Control** on, Windows may block it with no "Run anyway": check the SHA-256, then either turn Smart App Control off for the install or wait for the signed build.

**Requirements:** Windows 10 or 11 (64-bit; only Windows 11 with an NVIDIA GPU has been tested), a Slippi Dolphin install and a Melee NTSC 1.02 ISO (Lunar does not provide one). Linux is experimental. There is no Mac version.

### Updating from 2.0.0-beta.9 (or any 2.x beta)

Your projects and settings are kept. Run the new installer over the old one, or use **Help > Check for Updates** in the app. If the update banner does not appear on its own (older betas could miss it), download the installer above and run it: it installs over the old version. Projects made by a 2.x beta open in 3.x. Keep a copy of projects you care about before updating, in case you want to go back to the beta.

### Known issues

- Windows 10, AMD and Intel graphics, and Linux are not tested yet and may not work.
- If your Windows user name or profile folder has non-ASCII characters, recording uses a plain folder under `C:\ProgramData` for Dolphin's temporary files; report anything odd.
