## Lunar Clipper 3.0.2

New Slippi games come in by themselves, and clips can end on the GAME! screen.

### What's new

- **Import new Slippi games automatically:** turn it on in **Settings > Project**. Clipper watches the folder the Slippi Launcher saves your replays to, and each game you play is added to the open project as soon as it ends (games played while Clipper was closed come in the next time you open it). Off by default.
- **Include the GAME! ending:** turn it on in **Settings > Recording**. A clip that ends at the end of its game (for example a combo that takes the last stock) keeps recording through the last KO and the GAME! screen, about 2 seconds more (a game that ended in a quit-out has no GAME! screen and is left as it is). Off by default.

### Install

| System | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | `Lunar-Clipper-Setup-3.0.2.exe` |
| Ubuntu / Debian | `Lunar-Clipper-3.0.2.deb` (recommended) |
| Other Linux | `Lunar-Clipper-3.0.2.AppImage` (needs `libfuse2`; see the README) |

Compare a download with `SHA256SUMS.txt` (`sha256sum` on Linux, `Get-FileHash` in Windows PowerShell).

**Already on 3.0.0 or 3.0.1?** Clipper offers the update itself at startup (or use **Help > Check for Updates**). Your projects and settings are kept.

**Windows will warn you the first time.** This installer is not code-signed yet. SmartScreen shows "Windows protected your PC": click **More info, then Run anyway**. On Windows 11 with **Smart App Control** on, Windows may block it with no "Run anyway": check the SHA-256, then either turn Smart App Control off for the install or wait for the signed build.

**Requirements:** Windows 10 or 11 (64-bit; only Windows 11 with an NVIDIA GPU has been tested), a Slippi Dolphin install and a Melee NTSC 1.02 ISO (Lunar does not provide one). Linux is experimental. There is no Mac version.

### Known issues

- Windows 10, AMD and Intel graphics, and Linux are not tested yet and may not work.
