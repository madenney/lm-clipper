# Changelog

The release history is kept in two places, both written for players:

- **In the app:** Settings > About > What's new (the source is
  [`src/constants/changelog.ts`](src/constants/changelog.ts)).
- **On GitHub:** the notes of each [release](https://github.com/madenney/lm-clipper/releases).

Versions follow [Semantic Versioning](https://semver.org/). This file used to be a hand-kept
list that stopped at 0.2.0 (2026-02-07, the SQLite backend and the concurrent filter workers);
everything since is in the places above.
